# 02 · 编译环境（VMware + Ubuntu）搭建指南

> 目标：一台能编译 LineageOS 23.x（Android 16）的 Ubuntu 虚拟机。
> 你不需要一次配完美，但**磁盘和内存必须先给够**，否则 sync 到一半就废。

## 一、硬件分配（在 VMware 里设，不是 Ubuntu 里）

| 项目 | 最低 | 推荐 |
|---|---|---|
| CPU 核心 | 8 | 12–16（物理机有多少给一半） |
| 内存 | 16 GB | 32 GB |
| 磁盘 | 400 GB | 500–600 GB（**厚置备**，别用精简置备） |
| 交换 | 8 GB swap | 16 GB swap |
| 显卡 | 关 3D 加速（AOSP 编译不需要） | — |

> AOSP 16 源码 ~150GB，out 目录 ~150GB，ccache 再 100GB。**磁盘虚报会直接导致编译失败**。

## 二、Ubuntu 版本

- **Ubuntu 24.04 LTS（推荐）** 或 22.04 LTS，64 位。
- 必须装 **VMware Tools**（`open-vm-tools-desktop`），否则共享文件夹/剪贴板不可用。
- 给虚拟机开 **嵌套虚拟化**（VMware 设置 → 处理器 → 虚拟化 Intel VT-x/EPT 或 AMD-V/RVI），否则 qemu 相关步骤会报错。

## 三、系统内基础配置

```bash
# 1. 更新
sudo apt update && sudo apt upgrade -y

# 2. 安装构建依赖（Ubuntu 22.04/24.04 通用，AOSP 16 官方列表）
sudo apt install -y \
  bc bison build-essential ccache curl flex g++-multilib gcc-multilib git git-lfs gnupg \
  gperf imagemagick lib32readline-dev lib32z1-dev libelf-dev liblz4-tool libsdl1.2-dev \
  libssl-dev libxml2 libxml2-utils lzop pngcrush rsync schedtool squashfs-tools \
  xsltproc zip zlib1g-dev unzip python3 python-is-python3 openjdk-21-jdk

# 3. 配 git
git config --global user.name  "你的名字"
git config --global user.email "你的邮箱"
git lfs install

# 4. 配 ccache（省一半重复编译时间）
echo 'export USE_CCACHE=1'            >> ~/.bashrc
echo 'export CCACHE_DIR=$HOME/.ccache' >> ~/.bashrc
source ~/.bashrc
ccache -M 100G
```

> **JDK 版本**：Android 16 需要 **OpenJDK 21**。如果系统自带 17，用 `update-alternatives --config java` 切到 21。

## 四、安装 repo 工具

```bash
mkdir -p ~/bin
curl https://storage.googleapis.com/git-repo-downloads/repo > ~/bin/repo
chmod a+x ~/bin/repo
echo 'export PATH=$HOME/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
repo --version
```

## 五、同步 LineageOS 源码（A16 分支）

```bash
mkdir -p ~/android/lineage && cd ~/android/lineage
repo init -u https://github.com/LineageOS/android.git -b lineage-23.0 --git-lfs
repo sync -c -j$(nproc --all) --force-sync --no-clone-bundle --no-tags
```

> 分支名以 LineageOS 官方当时实际的 A16 分支为准（可能叫 `lineage-23.0`/`lineage-23.1`）。
> 首次 sync 通常 1–3 小时，取决于网络；中断了重跑同一条命令即可。

## 六、自检

在仓库目录下跑：

```bash
cd ~/android/lineage
source build/envsetup.sh
lunch 2>&1 | head   # 能列出产品列表 = 环境通了
```

看到设备列表/报"no product"都正常，只要 envsetup 不报错。

## 七、常见坑

- **磁盘不够**：`df -h` 看 `~/` 分区，务必 ≥ 400G 可用。
- **内存不足 OOM**：加 swap 或开 `zram`；8G 内存基本编不动。
- **JDK 不对**：报 `Unsupported class file major version` → 切 JDK 21。
- **Python**：`python` 必须指向 python3（`python-is-python3` 包）。
- **ccache 没开**：`ccache -s` 查看命中率。
